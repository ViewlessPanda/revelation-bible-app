# Security policy

## Supported versions

Revelation is pre-alpha. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately, using GitHub's private
vulnerability reporting: open the **Security** tab of this repository and choose
**Report a vulnerability**. Please do not open a public issue or pull request for it.

Include what you found, how to reproduce it, and which commit or version you
tested. You will get a reply in the same private report. Please give the maintainer
reasonable time to fix the problem before you share details publicly.

## Scope

The app runs offline and has no accounts. Reports about the integrity of the
content files (for example a way to make the app show altered scripture text), the
handling of untrusted input, or the build and release checks are especially welcome.
